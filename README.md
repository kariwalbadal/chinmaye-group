# Chinmaye Hotels — brand site

Production website for **Chinmaye Hotels** (client work), live at [chinmaye.in](https://chinmaye.in).

Multi-property hotel brand site: property pages (Inn, Grand, Deoghar), menus, and
integration with the group's STAAH booking engine on masked subdomains
(see [DOMAINS.md](DOMAINS.md) for the domain and namespace scheme).

## Stack

- Static HTML/CSS/JS, deployed via GitHub Pages with a custom domain
- STAAH booking engine (hosted externally, masked under `booking.*` subdomains)
- SEO plumbing: sitemap, robots.txt, llms.txt
